# PDDP APK Security Assessment

## Overview

This repository contains the work carried out during the security assessment of **PDDP.apk** as part of an internship task.

The assessment involved inspecting the APK, examining its contents and resources, decompiling the application, reviewing the application structure and security-related information, and documenting the security findings.

## Tools Used

### 1. Kali Linux
Kali Linux was used as the main operating system and security testing environment for the APK assessment.

### 2. Apktool
**Apktool** was used to decode and inspect the APK package, including its resources and Android application structure. It was also used during the APK modification and recompilation process.

### 3. JADX
**JADX** was used to decompile the APK and inspect the application's source code in a more readable Java-like form.

### 4. Git
**Git** was used for version control and to track changes made during the assessment, including different stages of the APK analysis and modification.

### 5. GitHub
**GitHub** was used to store, organize, and document the project files, assessment results, security report, and different branches created during the work.

## Assessment Process

The main activities carried out during the assessment included:

1. Obtaining and identifying the PDDP APK file.
2. Inspecting the contents and structure of the APK.
3. Examining Android application resources and the manifest.
4. Decompiling the APK using JADX.
5. Reviewing the decompiled application files and resources.
6. Assessing the security of the APK and documenting the findings.
7. Preparing a security report for the assessed file.
8. Modifying the application icon as part of the practical APK modification exercise.
9. Recompiling the modified APK.
10. Organizing the assessment work using Git and GitHub.

## Repository Structure

Important files and branches in this repository include:

- **PDDP.apk** – Original APK used for the assessment.
- **PDDP_modified.apk** – Recompiled APK containing the modified application icon.
- **SECURITY REPORT ON PDDP.apk.txt** – Security assessment report.
- **PDDP_jadx** – Decompiled APK files and resources produced using JADX.
- **icon.png** – Preserved original application icon.
- **main** – Main project branch.
- **security-report** – Branch containing the security report.
- **jadx-decompilation** – Branch containing the JADX decompilation.
- **icon-change** – Branch containing the icon modification and recompiled APK.
- **the-original-file-icon** – Branch preserving the original icon.
- **unzipped** – Branch containing extracted APK contents.

## Purpose

The purpose of this project was to gain practical experience in Android application security assessment, APK analysis, reverse engineering, documentation, and basic application modification.

## Disclaimer

This project was carried out for educational and internship purposes. The assessment was performed on the APK provided for the task.
